# CHIP Annotation

The pipeline annotates ctDNA variants with CHIP (Clonal Haematopoiesis of
Indeterminate Potential) flags to help distinguish tumour-derived variants from
blood-borne clonal variants.

## Overview

CHIP variants typically exhibit:
- VAF between 0–10% (most commonly 1–3%)
- Fragment lengths consistent with hematopoietic cfDNA (~160–165 bp), longer
  than tumour-derived ctDNA (~130–145 bp)
- Occurrence in a defined set of CHIP driver genes

The annotation is only applied in **ctDNA mode** (UMI deduplication).

## INFO Fields Added

| Field | Range | Description |
|-------|-------|-------------|
| `CHIP_GENE` | 0–2 | 0 = not a CHIP gene; 1 = minor gene; 2 = major gene (DNMT3A, TET2, ASXL1) |
| `CHIP_VAF` | 0–2 | 0 = outside range; 1 = 0–10% (tier 1); 2 = 1–3% (tier 2) |
| `CHIP_FRAG` | -1/0/1/. | 1 = alt reads above abs threshold AND ratio vs ref; -1 = short tumour-like fragments; 0 = not flagged; . = too few reads or no ref reads |
| `CHIP_FRAG_ALT` | float | Mean fragment length of alt-supporting reads |
| `CHIP_FRAG_REF` | float | Mean fragment length of ref-supporting reads |
| `CHIP_HOTSPOT` | 0/1 | 1 = variant found in Bick et al. 2020 CHIP population data (contributes 4 to score) |
| `CHIP_COSMIC_HEMATO` | 0–N | Count of haematological tumour samples in COSMIC v97 with this variant (capped at 4 in score; 0 if below cosmic_min_count or excluded gene) |
| `CHIP_CONSEQUENCE` | 0/1 | 1 = LoF in a LoF-CHIP gene or missense in a missense-CHIP gene |
| `CHIP_SCORE` | integer | Combined score; practical max ~11; filter threshold ≥5 |

## Scoring

```
CHIP_SCORE = CHIP_GENE (0-2)
           + CHIP_VAF (0-2)
           + CHIP_FRAG (-1/0/1)
           + min(CHIP_HOTSPOT × 4, 4)
           + min(CHIP_COSMIC_HEMATO, 4)
           + CHIP_CONSEQUENCE (0-1)
```

CHIP_HOTSPOT and CHIP_COSMIC_HEMATO co-occur at well-known loci (e.g. DNMT3A R882),
giving a practical maximum of ~11. The filter threshold is ≥5.

## Reference Data

### Gene Lists (`chip_genes.yaml`)
Curated lists of CHIP genes split into tiers:

- **Major genes** (CHIP_GENE=2): DNMT3A, TET2, ASXL1
- **Minor genes** (CHIP_GENE=1): JAK2, SF3B1, PPM1D, CBL, GNB1, BCOR, SRSF2
- **LoF-CHIP genes** (for CHIP_CONSEQUENCE): DNMT3A, TET2, ASXL1, BCOR, CBL, PPM1D, SRSF2
- **Missense-CHIP genes** (for CHIP_CONSEQUENCE): JAK2, GNB1, SF3B1, DNMT3A
- **COSMIC exclude genes**: TP53 (excluded because TP53 mutations are common in all
  haematological cancers, not specifically in CHIP)

Source: `Twist_Solid_pipeline_files/chip/chip_genes.yaml`

### CHIP Hotspot VCF (`chip_hotspot_hg19_YYYYMMDD.vcf.gz`)
SNV positions seen in ≥5 healthy individuals in Bick et al. 2020 (Nature
Genetics, 97,691 whole genomes). TP53 is excluded as its mutations are
frequently tumour-derived. The `CNT` INFO field records the number of
individuals carrying the variant.

Generated by `Twist_Solid_pipeline_files/chip/create_chip_hotspot_vcf.py`.

### COSMIC Haematological VCF (`cosmic97_hemato_hg19_YYYYMMDD.vcf.gz`)
SNV positions from COSMIC v97 filtered to `haematopoietic_and_lymphoid_tissue`
with ≥10 samples (CNT≥10). Only substitution SNVs are included. A runtime
minimum count (`cosmic_min_count`, default 20) is applied in the annotation
script to further reduce low-confidence entries. The `CNT` INFO field records
the number of haematological tumour samples.

Generated by `Twist_Solid_pipeline_files/chip/filter_and_liftover_vcf.py`
from the COSMIC `CosmicMutantExport.tsv` download.

## Configuration Parameters

All parameters are set under `chip_annotation:` in the pipeline config.

| Parameter | Default | Description |
|-----------|---------|-------------|
| `chip_genes_file` | — | Path to `chip_genes.yaml` |
| `chip_hotspot_vcf` | — | Path to bgzipped+tabixed CHIP hotspot VCF |
| `cosmic_hemato_vcf` | — | Path to bgzipped+tabixed COSMIC haematological VCF |
| `min_alt_reads` | 5 | Minimum alt-supporting reads for fragment analysis |
| `frag_abs_threshold` | 150 | Minimum mean alt fragment length (bp) for CHIP_FRAG=1 |
| `frag_ratio_threshold` | 1.1 | Minimum alt/ref fragment length ratio for CHIP_FRAG=1 |
| `frag_short_threshold` | 145 | Mean alt fragment length (bp) below which CHIP_FRAG=-1 |
| `cosmic_min_count` | 20 | Minimum COSMIC CNT to contribute to score |
| `vaf_tier1_min` | 0.0 | Minimum AF for CHIP_VAF tier 1 |
| `vaf_tier1_max` | 0.10 | Maximum AF for CHIP_VAF tier 1 |
| `vaf_tier2_min` | 0.01 | Minimum AF for CHIP_VAF tier 2 |
| `vaf_tier2_max` | 0.03 | Maximum AF for CHIP_VAF tier 2 |
